## 📌 Title
FastRobot for Java — High‑FPS Screen Capture & Automation

## 📝 Description
FastRobot is a high-performance native alternative to `java.awt.Robot`. 
It uses a native Windows backend (DirectX DXGI + DirectInput) to achieve 10–17x faster capture speeds and zero-latency input events.

### 🚀 Key Features:
- **Ultra-Fast Capture**: 60+ FPS via DirectX Desktop Duplication.
- **Zero-Latency Input**: DirectInput for mouse and keyboard simulation.
- **Efficient Pipelines**: Native memory buffers prevent GC stalls.
- **Superior Speed**: Up to 17x faster than the standard Java Robot API.

### 🔥 Use Cases:
- High-Performance Computer Vision & AI
- Gaming Automation & Performance Tools
- Real-time Desktop Streaming & Recording
